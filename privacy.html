Privacy Policy

นโยบายความเป็นส่วนตัวของ Hermes VPS

1. ขอบเขต

นโยบายนี้อธิบายการใช้ข้อมูล Google โดยระบบ Hermes VPS สำหรับงานส่วนตัวที่เจ้าของบัญชีอนุญาต และเว็บไซต์แนะนำระบบนี้

2. ข้อมูลที่ระบบเข้าถึง

ตามสิทธิ์และงานที่อนุญาต ระบบอาจเข้าถึงข้อมูลไฟล์และเนื้อหาใน Drive, Sheets และ Docs รวมถึงกิจกรรมใน Calendar ข้อมูลอาจรวมถึงบันทึกส่วนตัวหรือข้อมูลสุขภาพที่เจ้าของบัญชีเลือกให้ระบบประมวลผล การเชื่อมต่อใช้ OAuth token ไม่ใช้รหัสผ่าน Google และไม่ได้ขอสิทธิ์ Gmail หรือ Google Contacts

3. วัตถุประสงค์และสิทธิ์การเขียน

ใช้ข้อมูลเพื่ออ่าน จัดระเบียบ สรุป วิเคราะห์ เก็บประวัติ หรือดำเนินการตามคำสั่งที่ได้รับอนุญาต สิทธิ์ Google API ที่ขออาจเป็นสิทธิ์อ่านและเขียน การจำกัดไฟล์หรือโฟลเดอร์ในงานหนึ่งเป็นข้อจำกัดระดับแอป ไม่ใช่การลดขอบเขต OAuth ของบัญชีทั้งหมด

4. การจัดเก็บ

ระบบอาจเก็บไฟล์ต้นฉบับ สำเนาข้อมูล ประวัติที่แปลงรูปแบบแล้ว และบันทึกการประมวลผลไว้บนเซิร์ฟเวอร์ที่ผู้ดูแลควบคุม Credentials แยกจากหน้าเว็บและไฟล์สาธารณะ สำเนาข้อมูลและประวัติอาจคงอยู่จนกว่าผู้ดูแลจะลบหรือจัดการตามวัตถุประสงค์ของงาน ไม่มีการรับประกันว่าการถอน OAuth จะลบสำเนาที่เก็บไว้แล้วโดยอัตโนมัติ

5. ผู้ให้บริการภายนอก

เมื่อใช้งานการวิเคราะห์ด้วยผู้ช่วย AI เนื้อหาที่เลือกใช้ในงานอาจถูกส่งให้ผู้ให้บริการ AI ตามการตั้งค่าของผู้ดูแล การส่งผลลัพธ์ผ่านช่องทางข้อความอาจเกี่ยวข้องกับผู้ให้บริการช่องทางนั้นด้วย ข้อมูลจึงไม่ได้ประมวลผลเฉพาะบนเซิร์ฟเวอร์ส่วนตัวเสมอไป การเก็บรักษาและใช้ข้อมูลของผู้ให้บริการเหล่านี้ขึ้นกับเงื่อนไขและการตั้งค่าของบริการนั้น

ไม่ขายข้อมูล Google ไม่ใช้เพื่อโฆษณา และไม่เผยแพร่ข้อมูลส่วนตัวบนเว็บไซต์แนะนำนี้

6. ถอนสิทธิ์และลบข้อมูล

เจ้าของบัญชีสามารถถอนสิทธิ์ที่ Google Account — Third-party connections การถอนสิทธิ์หยุดการเข้าถึงใหม่ แต่ไม่ได้ลบไฟล์ต้นฉบับใน Google หรือสำเนาบนเซิร์ฟเวอร์โดยอัตโนมัติ สำหรับการลบสำเนาและประวัติ ให้ติดต่อผู้ดูแลผ่านช่องทางส่วนตัวที่ใช้งานอยู่

7. เว็บไซต์สาธารณะ

หน้าเว็บนี้ไม่มีแบบฟอร์มรับข้อมูล Google ไม่มีโค้ดวิเคราะห์ผู้เข้าชมที่แอปเพิ่มเอง และไม่เก็บ OAuth token ผู้ให้บริการโฮสต์อาจประมวลผลข้อมูลการเข้าถึง เช่น IP address และ HTTP requests ตามนโยบายของตน หากเผยแพร่ผ่าน GitHub Pages ให้ดู GitHub Privacy Statement
